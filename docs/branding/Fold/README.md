# Fold icon

`Fold/Fold.icon` is the canonical app icon, authored as a native Icon Composer document. It contains four editable SVG layers recreated from the selected folded-ribbon concept: front play face, red bookmark fold, lower return and upright ribbon. The numbered source SVGs here remain editable in vector tools. Layer ordering in the native document runs front to back.

The charcoal background, native specular edges, neutral shadows and 15% translucency are rendered by Icon Composer. No concept screenshot, baked shadow or baked rounded-square mask is used as a foreground layer. Default and Dark retain the white ribbon and red bookmark; Dark uses the system's darker background treatment. Mono/tinted appearances are generated by the same native asset. Xcode generates compatible icon renditions for older supported iOS releases.

`icon-default.png`, `icon-dark.png` and `icon-tinted.png` are native Icon Composer exports for review and documentation. `FoldMark.imageset` uses the Default/Dark exports only for the small in-app brand mark; the installed app icon uses the layered `.icon` document.

## Seam alignment

The foreground taper and lower return share the same straight baseline, from `(405,831)` to `(817,593)`. Their edge endpoints and tangent controls align to that line, so the bottom-right fold meets the triangle without a protruding tip. Both the native asset and the editable source copies use this geometry. `icon-light-64.png` and `icon-dark-64.png` are native Icon Composer renders at small icon size.

The lower triangle and red bookmark meet at the same top `(405,628)` and bottom `(405,831)` vertices. Lowering the triangle's left top by 16 SVG pixels removes the step above the bookmark; its accepted lower-right baseline remains unchanged. Default and Dark retain the original shared palette.

The upright layer now keeps a straight vertical edge to `(405,628)`, removing its rounded inward hook at the bookmark junction. The front layer's upper corner uses a circular SVG arc (radius `84.858277931`) tangent to both the vertical side and the unchanged top diagonal. This removes the former curve-to-line angle break. The `light/dark-bookmark-detail.png` and `light/dark-upper-detail.png` files are enlarged crops of native renders for inspecting these two junctions.

## Identity and build migration

The app, source folders, Xcode project, targets and primary scheme are named Fold. Bundle identifiers, Keychain service/access group, signing team/profiles, notification identifiers, offline storage and the existing App Store Connect app remain unchanged.

`TAClient.xcodeproj` is a compatibility symlink to `Fold.xcodeproj`, and the shared `TAClient` scheme aliases the same Fold target. These keep existing Xcode Cloud and local build invocations working during the rename. New invocations should use `Fold.xcodeproj` and scheme `Fold`. The original untracked local Xcode Cloud manifest is preserved and is not part of this branding commit.

Apple's [Icon Composer integration guide](https://developer.apple.com/documentation/xcode/creating-your-app-icon-using-icon-composer) describes the native asset and automatic compatibility renditions.
